For new developers, start with:
1. [Development Setup](./development-setup.md) - Get your environment running
2. [Naming Conventions](./naming-conventions.md) - Understand our file organization
3. [UX Guidelines](./ux-guidelines.md) - Learn our design approach

## Technology Stack

- **Framework**: React with TypeScript
- **Routing**: TanStack Router (file-based)
- **Styling**: Tailwind CSS
- **State Management**: TanStack Store
- **Data Fetching**: TanStack Query + Route Loaders
- **Testing**: Vitest
- **Linting**: Biome
- **Components**: Shadcn UI

## Additional Resources

Files prefixed with `demo` can be safely deleted. They are there to provide a starting point for you to play around with the features you've installed.
